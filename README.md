# Discord Bot Project For Slay.one
A discord bot that provides a better gaming experience for Slay.one players.
> Note: This was designed for small player base, some features might not work well once the playerbase gets big.
> Note 2: This wasn't designed for long term purpose, so it can have many bad practices for fast feature delivering.

# Features
1. Monitoring Slay.one activity.
2. Notification system of Slay.one activity.
3. Replay saving.
4. External Slay.one ranking.
5. Monitoring Slay.one resource update (for dev).
